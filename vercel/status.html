연결 주소

Base URL:

Chat: POST /v1/chat/completions · 모델 목록: GET /v1/models · 인증: Authorization: Bearer <통합 API 키>

서버리스 배포라 관리용 대시보드와 키 편집 화면은 닫혀 있습니다. 설정은 Vercel 환경 변수(FREEAPI_CONFIG_JSON)로 바꿉니다.

연결 테스트

통합 API 키는 이 브라우저 탭 메모리에만 있고 저장되지 않습니다. 요청 헤더로만 전송됩니다.
